# alfahack-research: свободный LLM-агент с закрытой валидацией

Решение для Alfa Hack AutoML. Табличная задача (классификация или регрессия) решается LLM-агентом (Qwen3.8-27B)
с одним инструментом `run_python`. Агент сам делает EDA, придумывает признаки, пробует модели и ансамбли.
Главное в решении не агент, а то, как проверяется его результат.

## Идея

Агент, который сам оценивает свои улучшения, подгоняется под свою валидацию. В первом же эксперименте на
регрессии он улучшил средний скор на своих фолдах (55.8 → 50.2 на первом, 43.9 → 42.1 на третьем),
а на закрытом годе стало хуже (50.2 → 65.7). Поэтому решение устроено так:

1. **Задача понимается без LLM** (`fa_task.py`): файлы, таргет и id по `sample_submission`, метрика по тексту `task.md`,
   тип задачи. Колонка времени — та, у которой все значения в test строго больше, чем в train.
2. **Закрытая отложенная часть, агент её не видит.** Для временных данных это последние периоды (до 15% строк),
   иначе случайные 15% со стратификацией. На остальном строятся фолды: расширяющееся окно по последним трём
   периодам или 5-fold.
3. **Запасной ответ записывается до запуска агента:** простой LightGBM на всём train.
4. **Агент работает в цикле** `run_python` до дедлайна (180 минут минус резерв). Оценка через `evaluate.py`
   по заданным фолдам; для временных задач в промпте требуется улучшать самый поздний фолд, а не только среднее.
5. **Выбор победителя:** `best_pipeline.py` агента и стартовый пайплайн обучаются на inner и сравниваются на
   отложенной части. Агент побеждает только если строго лучше. Победитель переобучается на всём train.
6. **Предохранители:** сторожевой таймер завершает процесс за 90 секунд до лимита (`submission.csv` к этому
   времени уже записан); запись файла атомарная; при любом сбое остаётся запасной ответ.

```
task.md ─► fa_task (тип, метрика, время) ─► split: inner / holdout (закрыт)
                                         ├► baseline LightGBM ─► submission.csv (запас)
                                         └► агент (run_python, evaluate.py по фолдам) ─► best_pipeline.py
holdout: agent vs baseline ─► победитель ─► refit на всём train ─► submission.csv
```

## Результаты

Замер на двух публичных задачах, **закрытая отложенная часть**, один запуск на задачу, 70 минут вместо 180,
LLM через VseLLM (та же модель).

| Задача | Метрика | Стартовый LightGBM | Агент | Шагов агента |
|---|---|---|---|---|
| Регрессия (`site_eui`, test — год 6) | RMSE ↓ | 50.18 | **44.30** (−11.7%) | 33 |
| Мультикласс (`attack_cat`, 10 классов) | macro F1 ↑ | 0.5858 | **0.6009** (+0.015) | 18 |

Что нашёл агент на регрессии: лог-таргет с поправкой на смещение (smearing), веса образцов, растущие с годом,
климатические и площадные признаки, 2 сида. CatBoost и XGBoost прироста не дали. На мультиклассе: лог-признаки
и sqrt-балансировка весов; масштабирование вероятностей по классам он проверил и отклонил.

## Структура

| Файл | Назначение |
|---|---|
| `solution.py` | точка входа платформы (`python solution.py task.md`), оркестрация и выбор победителя |
| `fa_task.py` | разбор задачи, отложенная часть, фолды |
| `fa_agent.py` | цикл агента: LLM + `run_python`, обрезка контекста |
| `fa_templates.py` | стартовый пайплайн, `evaluate.py` и `runner.py` для агента |
| `fa_metrics.py` | метрики |
| `build_zip.py` | ZIP для платформы (только корневые `.py` и `requirements.txt`) |
| `platform/requirements.txt` | список библиотек платформы |
| `tests/` | тесты на разбор задачи, отложенную часть, агента-субпроцесс и выбор победителя |

## Запуск

```bash
pip install -r requirements.txt
export OPENAI_BASE_URL=... OPENAI_API_KEY=...          # OPENAI_MODEL необязательна
FA_TOTAL_MIN=70 python solution.py path/to/task.md     # FA_TOTAL_MIN — для коротких локальных прогонов
python build_zip.py                                     # dist/solution.zip для загрузки на платформу
pytest
```

Данные соревнования в репозиторий не включены. Рядом с `task.md` ожидаются `train.csv`, `test.csv` и
`sample_submission.csv` (в любой подпапке).

## Ограничения платформы, учтённые в коде

8 CPU, 32 ГБ, 3 часа, без интернета и предобученных моделей; в ZIP только корневые `.py` и `requirements.txt`;
`submission.csv` кладётся рядом с `task.md` в порядке строк `test.csv`.
